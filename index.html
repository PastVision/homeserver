Privacy

This site is static. It has no analytics, tracking pixels, account system, or server-side storage. Settings and the administrative secret are sent directly from your browser to the backend URL you enter. They are never uploaded to GitHub. The administrative secret is not written to localStorage, sessionStorage, cookies, or the URL.

The backend stores installation configuration on the server and exposes only an opaque installation identifier. Generated playback URLs use signed, expiring capabilities. Revoke an installation if a link is exposed.
